🌼 Backup your little garden

Save a copy of your subjects, study sessions, and timer so you can restore them later.

Where does the backup go?
When you download it, the JSON backup file is saved on that device—usually in the Downloads folder. It is not automatically uploaded to Google Drive or the internet. You can move it to Google Drive yourself if you want an extra copy.

Restoring a backup replaces the current app data on this device. Export the current data first if you want to keep both copies.
